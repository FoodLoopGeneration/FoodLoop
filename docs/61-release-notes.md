# 61 — Release Notes

## Versione 1.0.0
- Data di rilascio: 23/02/2026
- Stato: Completa
- Sviluppato da: Team FoodLoop

### Funzionalità
- Gestione Inventario (Dispensa): CRUD completo degli ingredienti con gestione di quantità, unità di misura e date di scadenza
- Ricettario Multimediale: Supporto al caricamento di immagini
- Sezione "Cosa cuciniamo": Sezione che mostra ricette, anche di altri utenti, fattibili con gli ingredienti presenti in dispensa
- Pannello controllo utenti admin: L'admin può eliminare gli utenti da un pannello di controllo dedicato

### Miglioramenti futuri
- Notifiche Scadenze: Implementazione di un task schedulato (Spring @Scheduled) per inviare alert sugli ingredienti vicini alla scadenza
- Dashboard Statistica: Visualizzazione grafica dei consumi e degli sprechi ridotti.
