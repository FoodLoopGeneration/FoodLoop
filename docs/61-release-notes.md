# Release Notes – FoodLoop

## **Versione 1.0.2**
**Data di rilascio:** 25/02/2026
**Stato:** Completata
**Sviluppato da:** Team FoodLoop

### Nuove Funzionalità
- **Filtri Avanzati Ricette:** Potenziata la navigazione nella sezione "Tutte le Ricette".
- **Filtro Tempo:** Possibilità di filtrare i piatti in base ai minuti di preparazione.
- **Filtro Difficoltà:** Introdotto un nuovo selettore numerico (da 1 a 5) per identificare rapidamente la complessità della preparazione.
- **Newsletter Settimanale Scadenze:** Implementato un sistema automatizzato di Email Marketing tramite **Spring Mail** e **Spring Scheduling**.Ogni lunedì mattina gli utenti ricevono il riepilogo dei prodotti in scadenza nella propria dispensa e un tip.

### Prossimamente
- Introduzione del sistema di Voto per le ricette della community.
- Match parziale degli ingredienti (suggerimenti anche se manca un prodotto).
- Integrazione API Barcode per caricamento rapido dispensa.
